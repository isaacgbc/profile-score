<objective>
Build the quota enforcement service that sits between the rate limiter and the Apify scraper client. Four exports:
1. `checkQuota({userId, fingerprintHash, isCacheHit})` — throws `APIFY_QUOTA_EXCEEDED` if over limit, returns silently otherwise. Cache hits short-circuit (no quota charge).
2. `consumeQuota({userId, fingerprintHash})` — increments the appropriate counter (User.apifyScrapeCount OR AnonymousApifyUsage.scrapeCount). Called ONLY after a successful Apify call.
3. `getQuotaState({userId, fingerprintHash})` — returns `{remaining, plan}` for dashboard display. Does NOT mutate state.
4. `logUsage({userId, fingerprintHash, url, urlHash, cacheHit, apifyRunId, costUsd, success, errorCode, durationMs})` — append-only audit log to `ApifyUsageLog`.

Purpose: Centralize ALL quota logic in one module. The route handler (Plan 01-07) will orchestrate: fingerprint → cache check → quota check → scrape → consume → log. Every call path is tested against the Prisma mock from Plan 01-03.

Output: `apify-quota.ts` service + comprehensive unit tests covering free/paid/anon paths, cache-hit shortcut, and usage log append.
</objective>

    ```
    import { prisma } from "@/lib/db/client";

    export const APIFY_FREE_QUOTA = 1;

    export type QuotaCallerContext = {
      userId?: string | null;
      fingerprintHash?: string | null;
    };

    export async function checkQuota(
      ctx: QuotaCallerContext & { isCacheHit: boolean }
    ): Promise<void> {
      if (ctx.isCacheHit) return;

      if (ctx.userId) {
        const user = await prisma.user.findUnique({ where: { id: ctx.userId } });
        if (!user) throw new Error("APIFY_QUOTA_EXCEEDED");
        if (user.apifyScrapeQuota === null) return; // paid tier, unlimited
        if (user.apifyScrapeCount >= user.apifyScrapeQuota) {
          throw new Error("APIFY_QUOTA_EXCEEDED");
        }
        return;
      }

      if (ctx.fingerprintHash) {
        const row = await prisma.anonymousApifyUsage.findUnique({
          where: { fingerprintHash: ctx.fingerprintHash },
        });
        if (row && row.scrapeCount >= APIFY_FREE_QUOTA) {
          throw new Error("APIFY_QUOTA_EXCEEDED");
        }
        return;
      }

      throw new Error("APIFY_QUOTA_EXCEEDED");
    }

    export async function consumeQuota(ctx: QuotaCallerContext): Promise<void> {
      if (ctx.userId) {
        const user = await prisma.user.findUnique({ where: { id: ctx.userId } });
        if (!user) return;
        await prisma.user.update({
          where: { id: ctx.userId },
          data: {
            apifyScrapeCount: { increment: 1 },
            apifyFirstScrapeAt: user.apifyFirstScrapeAt ?? new Date(),
          },
        });
        return;
      }
      if (ctx.fingerprintHash) {
        const now = new Date();
        await prisma.anonymousApifyUsage.upsert({
          where: { fingerprintHash: ctx.fingerprintHash },
          create: {
            fingerprintHash: ctx.fingerprintHash,
            scrapeCount: 1,
            firstScrapeAt: now,
            lastScrapeAt: now,
          },
          update: {
            scrapeCount: { increment: 1 },
            lastScrapeAt: now,
          },
        });
      }
    }

    export async function getQuotaState(
      ctx: QuotaCallerContext
    ): Promise<{ remaining: number | null; plan: "free" | "starter" | "recommended" }> {
      if (ctx.userId) {
        const user = await prisma.user.findUnique({ where: { id: ctx.userId } });
        if (!user) return { remaining: 0, plan: "free" };
        if (user.apifyScrapeQuota === null) {
          const plan = user.activePlanId === "recommended" ? "recommended" : "starter";
          return { remaining: null, plan };
        }
        return {
          remaining: Math.max(0, user.apifyScrapeQuota - user.apifyScrapeCount),
          plan: "free",
        };
      }
      if (ctx.fingerprintHash) {
        const row = await prisma.anonymousApifyUsage.findUnique({
          where: { fingerprintHash: ctx.fingerprintHash },
        });
        const used = row?.scrapeCount ?? 0;
        return { remaining: Math.max(0, APIFY_FREE_QUOTA - used), plan: "free" };
      }
      return { remaining: 0, plan: "free" };
    }

    export async function logUsage(params: {
      userId?: string | null;
      fingerprintHash?: string | null;
      url: string | null;
      urlHash: string | null;
      cacheHit: boolean;
      apifyRunId?: string | null;
      costUsd: number;
      success: boolean;
      errorCode?: string | null;
      durationMs?: number | null;
    }): Promise<void> {
      try {
        await prisma.apifyUsageLog.create({
          data: {
            userId: params.userId ?? null,
            fingerprintHash: params.fingerprintHash ?? null,
            url: params.url,
            urlHash: params.urlHash,
            cacheHit: params.cacheHit,
            apifyRunId: params.apifyRunId ?? null,
            costUsd: params.costUsd as unknown as any,
            success: params.success,
            errorCode: params.errorCode ?? null,
            durationMs: params.durationMs ?? null,
          },
        });
      } catch {
        // fire-and-forget: never crash the caller on log failure
      }
    }
    ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Route handler -> quota service | Caller passes `userId` (server-side auth) + `fingerprintHash` (server-computed) |
| Quota service -> Prisma | Typed DB queries, no user-controlled SQL |
| Quota service -> logUsage | Sanitized inputMeta (urlHash only, not raw URL) |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 (T-08: auth bypass on plan-gating) | Elevation of Privilege | `checkQuota` | mitigate | `userId` is read from the Supabase auth session server-side in the route (Plan 01-07), never from client-provided headers or request body. `apifyScrapeQuota` is read from authoritative DB, not client cache. |
| T-06-02 (T-11: anonymous quota bypass via fingerprint rotation) | Elevation of Privilege | Anonymous quota path | accept | Residual risk — rotating IP+UA is possible. Mitigations: (a) rate limiter in Plan 01-04 caps 3/min per key, (b) fingerprint salt makes collision attacks harder, (c) logged in ApifyUsageLog for monitoring per T-11 acceptance. Further detection deferred. |
| T-06-03 (T-05: HMAC bypass on Creala webhook) | Tampering | N/A — this plan does not touch Creala | N/A | Plan 01-07 handles the single-line `apifyScrapeQuota: null` insertion inside the already-verified HMAC handler. This plan only READS `apifyScrapeQuota`. |
| T-06-04 (Race condition on quota increment) | Elevation of Privilege | `consumeQuota` | mitigate | Uses Prisma `{ increment: 1 }` atomic operation where available. If mock can't simulate, fetch-then-update is used — acceptable because the route-level rate limiter caps rate at 3/min per fingerprint, so concurrent increments are effectively impossible in a single Lambda invocation. |
| T-06-05 (logUsage failure crashes request) | DoS | `logUsage` | mitigate | Wrapped in try/catch; log write failures are swallowed. The caller's request succeeds or fails on its own merits, independent of audit log availability. Pattern matches existing `logError()` fire-and-forget convention. |

| T-06-07 (safe default — unknown caller denied) | Elevation of Privilege | `checkQuota` | mitigate | When BOTH `userId` and `fingerprintHash` are missing, the service throws `APIFY_QUOTA_EXCEEDED` (fail-closed). Test 9 enforces. |
